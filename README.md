## Preview
Open `index.html` in your browser. All assets and case-study pages work as relative paths.

## Publish for free using GitHub Pages
1. Create a public GitHub repository named `samirmihoubi2003.github.io` (assuming your GitHub username is `samirmihoubi2003`).
2. Upload **the contents of this folder** — with index.html at the repository root.
3. Commit to `main`.
4. Go to **Settings → Pages → Deploy from branch → main → /(root)**.
5. Visit `https://samirmihoubi2003.github.io` after deployment.
