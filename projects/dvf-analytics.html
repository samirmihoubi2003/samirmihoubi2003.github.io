DVF Île-de-France Analytics

Building trustworthy real-estate intelligence from public data.

The data problem

DVF source files are not immediately suitable for transaction-level analysis: properties and sales may occupy multiple source records, while missing values and anomalous prices require care.

My approach

Built a Python ETL pipeline with validation and deduplication, a PostgreSQL transaction-grain model and a star-schema mart. Added Docker-based integration and continuous integration checks with GitHub Actions.

Results and interpretation

The project compares local price patterns while retaining transaction grain. Recorded outputs are project-run results; the website does not suggest that an unfinished dashboard is live.

Methodological note

The definition of eligible transactions matters for price-per-square-metre estimates. Metrics should be interpreted with documented filters, property type and geographical scope.

Evidence & status

Published repository; large-run figures reflect recorded development logs. Power BI visuals are not presented as deployed.
