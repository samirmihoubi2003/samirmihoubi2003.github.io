Network Intrusion Detection

Evaluating how machine learning distinguishes malicious traffic.

The data problem

Network traffic is imbalanced and heterogeneous. Evaluation needs to account for the differences between normal traffic, attack classes and dataset splits.

My approach

Prepared CICIDS2017 data, experimented with Isolation Forest, autoencoders and a CNN-MLP model, then compared results with classification metrics and confusion matrices.

Results and interpretation

The reported F1 and accuracy derive from recorded experiments and must be interpreted in their respective evaluation conditions. They are not evidence of deployed production detection performance.

Methodological note

The portfolio makes no claim about unseen deployment, live threat protection or performance on independently collected traffic. Experimental split and leakage checks should accompany any published benchmark.

Evidence & status

Code repository is linked; detailed evaluation tables should be published for full reproducibility.
